# Excel compatibility fixtures

- `excel-golden.xlsx` / `excel-golden.tsv` — generated by Microsoft Excel 365
  with `scripts/make-excel-golden.ps1`. The TSV records the formula, displayed
  text, Excel type and raw `Value2` for each case.
- `hyo-sample.xlsx` — generated by `hyo-io` (`cargo run -p hyo-io --example
  save_sample`) and verified by opening it in Excel: formulas and cached values
  are read back correctly.

`cargo test -p hyo-io --test excel_golden` loads the workbook, recalculates it
with the Hyo engine and checks every case against Excel. Numeric comparisons
use a relative tolerance of `1e-12`.
